# SUPERASTRA identity

## Spellbook credit

The header displays "Magic by" followed by the official Spellbook wordmark.
The original SVG and a 174-pixel-wide PNG rendering are bundled in this folder.
The asset's original colors, geometry and aspect ratio are preserved.

Source: [spellbook.com](https://spellbook.com/), whose header uses
[this logo SVG](https://cdn.prod.website-files.com/66fc4a00d70e086034b6699f/67296a796f9b9a12470af11b_spellbook-logo.svg).
The Spellbook logo is a third-party brand asset and is not covered by the
project's MIT source-code license.

## SUPERASTRA logo

`superastra-logo.png` is the generated, full-resolution wordmark used by the
desktop UI. The app displays that same asset with integer downsampling. It has
an alpha channel and requires no additional image library at runtime.

Created using the built-in image-generation tool, for this project.

Generation prompt:

> Create a polished 16-bit console RPG title wordmark for a desktop emulator
> companion. Exact text SUPERASTRA, one horizontal line, all capitals. Chunky bold
> pixel art letterforms, readable at 450 pixels wide, beveled silver-white upper
> highlights transitioning into lavender and vivid violet lower faces, deep indigo
> pixel extrusion/shadow, crisp stepped edges. A small four-point golden pixel star
> integrated as an accent near the final A. SNES-era RPG title-screen aesthetic.
> Restrained and premium, no Nintendo logos, no characters, no additional words or
> tagline, no mockup. Wide horizontal asset; wordmark fills almost the entire width
> with modest padding and minimal vertical empty space. Very dark navy #080d24
> application header backdrop.
